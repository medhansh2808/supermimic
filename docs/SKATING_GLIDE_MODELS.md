# Skate dynamics and value study

This experiment starts from the final real-simulator glide controller (`artifacts/glide_search_v1/sustain/best.pt`) and the original SuperMimic+EMA motion-tracking checkpoint. It does not change the actor. All data are real executions in the skate-contact simulator. No walking reference is fed to the controller; the original actor receives a synthetic standing reference, and the learned glide residual supplies the propulsion corrections.

Collection starts each of 64 trajectories from rest with small initial tilt. Some trajectories use the original actor alone, while the others use small fixed perturbations around the learned glide controller. Three quarters of these independently perturbed episodes form the fitting split. The rest are held out. The same nominal skate physics and 0.3 m/s straight-speed target apply to both splits. Collection records executed actions, previous actions, state transitions, normalized physics context, true simulator rewards, termination, and critic inputs. The reward favors measured forward velocity, target speed and stability, with a fall penalty. It does not use the old standing-friendly motion-tracking reward. Episodes are never split across train and dev.

The world model begins at the original checkpoint and is fine-tuned on true one-step transitions. The report compares its held-out one-step state RMSE before and after fitting. The critic starts fresh and predicts discounted simulator rewards from the current state and goal. Its development episode RMSE is compared against a constant predictor. Both optimizers clip gradients and stop on non-finite losses. The best checkpoint for each is selected using the dev split. The actor performs zero updates.

Run `bash scripts/skate_glide_model_study.sh` on the 4090 after the glide search has finished. The output directory is `artifacts/glide_models_v1`; use `SKATE_MODEL_TAG=glide_models_v2` to create a separate study. Inspect `fit/report.json` for the model comparisons. `world_model.pt` and `critic.pt` are study checkpoints, not ready-made skating-policy weights.

This experiment can support the narrower conclusion that fine-tuning improves one-step prediction on held-out skating transitions, and that the critic predicts returns under nearby fixed skating controllers better than a constant baseline, if the reported errors improve. It does not establish useful long-horizon imagination, improved actor training, or generalization to new friction and disturbances. Those require a separate control experiment with real-simulator evaluation.
